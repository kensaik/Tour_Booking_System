## Hướng dẫn chụp ảnh

### Công cụ khuyến nghị

- **Windows:** Snipping Tool, Lightshot, or ShareX
- **Browser:** Chụp trực tiếp từ DevTools (F12 → screenshot)

### Kích thước khuyến nghị

- Desktop: 1920x1080
- Tablet: 768x1024
- Mobile: 375x667

### Quy tắc đặt tên file

```
{page}_{action}_{YYYYMMDD}.png

Ví dụ:
- login_success_20260510.png
- booking_confirm_20260510.png
- admin_dashboard_20260510.png
```
